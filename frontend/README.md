# StockVision - Frontend (Vue 3)

The StockVision frontend is a reactive, single-page application built with **Vue 3 (Composition API)** and engineered to provide a sleek, fast UI for stock analysis. 

## Architectural Overview

The application follows a standard modular layout for scalability and maintainability:

- **`src/views/`**: Contains the page-level route components (`DashboardView.vue`, `StocksView.vue`).
- **`src/stores/`**: Uses `Pinia` for global state management. The `stockStore.ts` centralizes data fetching, pagination state, and caching.
- **`src/services/`**: Houses the `api.ts` file, a lightweight abstraction layer for all `fetch` requests targeted at the Go Backend.
- **`src/types/`**: TypeScript interfaces and types enforcing strong typing for stock entities across components.

---

## Styling & Theme

The project relies entirely on **Tailwind CSS v4** without any heavy component libraries (like Vuetify/Quasar) to maximize rendering speed. 
The visual aesthetic utilizes:
- **Glassmorphism**: Semi-transparent backgrounds with backdrop blurring for a premium, modern feel.
- **Custom Color Palette**: Defined in `index.css`, enforcing strict color hierarchies (Primary, Accent, Warning, Danger) to clearly convey stock rating statuses visually.
- **Animations**: The `index.css` file includes custom `@keyframes` used heavily to animate content lazily loading (e.g. `animate-fade-in-up`) giving the dashboard an fluid feel.

---

## Core Features & Functionality

1. **Dashboard Home (`/`)**: 
   Displays critical business metrics (Total Stocks, Top Picks). Most notably, it surfaces the top 3 highest-scoring recommendations fetched from the backend's scoring engine.
   *Includes an interactive 'Sync Data' action to manually force a real-time data fetch against external APIs.*
   
2. **Stocks Directory (`/stocks`)**: 
   A comprehensive data table serving the full analyst history.
   - Server-side pagination and processing via the Pinia store.
   - Throttled search bar by Company, Ticker, or Brokerage.
   - Dynamic sorting across multiple axes (Rating, Upside %, etc).
   - Modal popups presenting a focused view of a single analyst action.

## Available Scripts

In the project directory, you can run:

### `npm install`
Installs all dependencies mapped in the `package.json`.

### `npm run dev`
Runs the app in the development mode utilizing Vite's Hot Module Replacement (HMR).
Navigate to [http://localhost:5173](http://localhost:5173) to view it in the browser. 
*(Ensure the Go Backend is running concurrently on port 8080, as API requests are configured to point there).*

### `npm run build`
Builds the app for production to the `dist` folder. It correctly bundles Vue in production mode and optimizes the build for the best performance.

### `npm run preview`
Boots up a local static web server to preview the production build generated by the command above.
